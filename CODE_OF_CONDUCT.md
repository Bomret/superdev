# Code of Conduct

superdev adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in every superdev space: issues, pull requests, discussions, and the wiki, and wherever
someone represents the project.

## In short

- Be respectful and kind. Disagree with ideas, not with people.
- Accept constructive feedback, and give it.
- Harassment, insults, sexualized language, and publishing someone's private information are not
  acceptable.

## Report a problem

Report behavior that breaks this code privately to the maintainer through GitHub:
<https://github.com/Bomret/superdev/security/advisories/new>. Mark the report as a conduct report. Every
report is reviewed and kept confidential.

The maintainer may remove, edit, or reject contributions, and may warn or ban a participant, following
the enforcement guidelines of the Contributor Covenant.
